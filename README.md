# clinic-walk

中葛西のクリニック（16.8m×5.4m）の間取りを、3Dで歩いて見られる内覧ウォークです。


- 公開ページ: https://wingman0527.github.io/clinic-walk/
- 案: 翔案・完成案、モリタ案（3台・2台）、ヨシダ案、空画案
- 操作: WASD で歩く／床をクリックでその場所へ／ドラッグで視点を回す（スマホはスティックとタップ）
- 平面図（A3横・1/50）: PDF は画面左下の「図面PDF」ボタン、または [完成案](pdf/final.pdf)・[翔案](pdf/sho.pdf)／CAD（DXF・Jw_cad / AutoCAD 用・実寸mm）は [完成案](cad/final.dxf)・[翔案](cad/sho.dxf)
- 消毒・滅菌・技工の機材と配置（完成案・A3横1枚：機材リストと大きさ・電気／水／エア）: [pdf/final_sterilization.pdf](pdf/final_sterilization.pdf)
- 内装見積用の図面（翔案のもの・A3横・4枚：仕上げ平面図と仕上表／建具・ガラス・窓／設備配置図（案）／造作家具と見積の前提）: [pdf/sho_estimate.pdf](pdf/sho_estimate.pdf)

`index.html` 1枚だけで動きます（3D表示に three.js を CDN から読み込みます）。
