# clinic-walk

中葛西のクリニック（16.8m×5.4m）の間取りを、3Dで歩いて見られる内覧ウォークです。

- 公開ページ: https://wingman0527.github.io/clinic-walk/
- 案: 翔案1〜翔案5、翔案6A・6B（X線室の最低寸法・推奨寸法）、モリタ案（3台・2台）、ヨシダ案、空画案
- 操作: WASD で歩く／床をクリックでその場所へ／ドラッグで視点を回す（スマホはスティックとタップ）
- 平面図PDF（A3横）: 画面左下の「図面PDF」ボタン、または [翔案1](pdf/sho1.pdf)・[翔案2](pdf/sho2.pdf)・[翔案3](pdf/sho3.pdf)・[翔案4](pdf/sho4.pdf)・[翔案5](pdf/sho5.pdf)・[翔案6A](pdf/sho6a.pdf)・[翔案6B](pdf/sho6b.pdf)
- 内装見積用の図面（翔案5・A3横・4枚：仕上げ平面図と仕上表／建具・ガラス・窓／設備配置図（案）／造作家具と見積の前提）: [pdf/sho5_estimate.pdf](pdf/sho5_estimate.pdf)

`index.html` 1枚だけで動きます（3D表示に three.js を CDN から読み込みます）。
